# Copilot Check

Paste a Hyperliquid wallet and see whether it's worth copying on Strike: how much of its profit Strike can copy, and how a copy would have done at your size.

Built for the Strike Finance hackathon (October 2026). Not affiliated with Strike Finance. General information only, not financial advice.

## Design

Styled with Ben Ryan's design kit (`css/`, `fonts/`), copied in before the hackathon window opened as existing brand work.

Fonts: Inter, Geist Mono and Atkinson Hyperlegible Next, each under the SIL Open Font License 1.1 (see `fonts/*-OFL.txt`).
